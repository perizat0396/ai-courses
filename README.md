# AI Курсы — платформа закрытых курсов по ИИ

Next.js 15 + Supabase (база, вход, хранилище файлов). Интерфейс на русском и казахском.

**Студент:** регистрируется сам (или вы создаёте ему аккаунт) → видит только те курсы, к которым вы открыли доступ → смотрит видео, читает уроки, скачивает материалы, проходит тесты, сдаёт задания, видит свой прогресс и ваши комментарии.

**Админ (вы):** создаёт курсы, модули и уроки (RU/KZ), загружает файлы и видео, добавляет тесты, открывает/закрывает доступ каждому студенту к конкретному курсу, проверяет задания.

Защита сделана на уровне базы (Row Level Security): даже зная ссылку на урок, студент без доступа его не откроет. Правильные ответы тестов студенту не отправляются — тест проверяется на сервере.

## Запуск — 4 шага (~20 минут, всё бесплатно)

### 1. Supabase (база данных)
1. Зарегистрируйтесь на [supabase.com](https://supabase.com) → **New project**. Регион — **Frankfurt (eu-central-1)**, придумайте пароль базы.
2. Откройте **SQL Editor → New query**, вставьте весь файл `supabase/schema.sql` → **Run**.
3. Ещё один запрос: файл `supabase/seed.sql` → **Run**. Появятся 2 курса со структурой уроков (черновики).
4. И третий: файл `supabase/ai.sql` → **Run** (ИИ-помощник и лимиты).
5. **Authentication → Sign In / Providers → Email**: если не хотите, чтобы студенты подтверждали почту, выключите **Confirm email**.
6. **Project Settings → API**: скопируйте `Project URL`, `anon public` и `service_role` — понадобятся на шаге 3.

### 2. GitHub
Загрузите папку проекта в новый **приватный** репозиторий (например, через GitHub Desktop или `git push`).

### 3. Vercel (хостинг сайта)
1. [vercel.com](https://vercel.com) → войти через GitHub → **Add New → Project** → выберите репозиторий.
2. В **Environment Variables** добавьте три переменные (значения из шага 1.6):

   | Имя | Значение |
   |---|---|
   | `NEXT_PUBLIC_SUPABASE_URL` | Project URL |
   | `NEXT_PUBLIC_SUPABASE_ANON_KEY` | anon public |
   | `SUPABASE_SERVICE_ROLE_KEY` | service_role (секрет!) |
   | `GEMINI_API_KEY` | ключ Gemini API (секрет!) |
   | `GEMINI_MODEL` | необязательно; по умолчанию `gemini-flash-latest` |
3. **Deploy**. Через 1–2 минуты получите адрес вида `ai-courses.vercel.app`.
4. Вернитесь в Supabase → **Authentication → URL Configuration** → в **Site URL** укажите этот адрес.

Свой домен (например, `ai.vku.edu.kz`) подключается в Vercel → Settings → Domains.

### 4. Сделайте себя администратором
Зарегистрируйтесь на сайте, затем в Supabase → SQL Editor выполните:
```sql
update public.profiles set role = 'admin' where email = 'ваш@email';
```
Обновите страницу — появится админка.

## Как работать

**Открыть доступ студенту.** Админка → **Студенты** → нажмите на название курса рядом со студентом (чёрный — доступ есть, белый — нет). Новые зарегистрировавшиеся без доступа видны на странице **Обзор** в блоке «Ждут доступа».

**Курс виден студенту, только если** у него есть доступ **и** курс отмечен «Опубликован». Пока наполняете курс — держите его черновиком.

**Урок.** Админка → Курсы → курс → нажмите на урок:
- **Видео** — ссылка YouTube (ставьте «Доступ по ссылке»), Vimeo, Google Drive или загрузка файла. На бесплатном тарифе Supabase файл до 50 МБ, поэтому длинные видео удобнее держать на YouTube.
- **Текст** — Markdown: `## Заголовок`, `**жирный**`, `- список`, `> выделенный блок`, `![](ссылка на картинку)`. Вкладка «Предпросмотр» показывает, как увидит студент.
- **Задание** — если поле заполнено, у урока появится форма ответа (текст + файл). Ответы приходят в **Задания**: «Принять» или «На доработку» с комментарием.
- **Файлы** — презентации, PDF, шаблоны; студент скачивает их со страницы урока.
- **Тест** — варианты ответа каждый с новой строки, номер правильного начиная с 1. Казахские варианты — в том же порядке.

Если казахский текст не заполнен, студенту с языком KZ показывается русский.

**ИИ-помощник (Gemini).** Работает, если задан `GEMINI_API_KEY`; без ключа просто скрыт.
- *Помощь:* на каждом уроке справа внизу кнопка «ИИ-помощник». Он знает текст и задание урока, отвечает на языке интерфейса (RU/KZ), объясняет и подсказывает, но задание за студента не делает.
- *Проверка:* после отправки задания ИИ сразу пишет студенту предварительный отзыв («Выполнено / Почти готово / Нужно доработать»). В разделе **Задания** вы видите тот же отзыв как черновик — кнопка «Вставить в комментарий», поправьте и нажмите «Принять» или «На доработку». Итоговое решение всегда ваше. Прикреплённые файлы ИИ не читает — только текст ответа.
- *Лимиты:* 40 вопросов и 15 проверок в день на студента (меняются переменными `AI_CHAT_DAILY_LIMIT`, `AI_REVIEW_DAILY_LIMIT`). У админа лимита нет.
- Ключ хранится только на сервере, студенты его не видят. Инструкции для ИИ (как отвечать, формат отзыва) — в `src/lib/gemini.ts`.

**Добавить студента самой.** Админка → Студенты → форма справа: email, пароль, курсы. Передайте человеку email и пароль.

**Сделать коллегу админом** — тот же SQL из шага 4 с его email.

## Для разработчика

```bash
npm install
cp .env.example .env.local   # заполнить ключи
npm run dev                   # http://localhost:3000
```

Структура:
- `supabase/schema.sql` — таблицы, RLS-политики, функции `submit_quiz` / `submit_assignment`, бакеты хранилища
- `supabase/seed.sql` — 2 стартовых курса
- `supabase/ai.sql` — отзывы ИИ и дневные лимиты; `src/lib/gemini.ts` — запросы к Gemini и промпты; `src/app/api/ai/*` — чат и проверка
- `src/app/(student)` — кабинет студента, `src/app/admin` — админка, `src/app/admin/actions.ts` — все изменения данных
- `src/lib/i18n.ts` — тексты интерфейса RU/KZ
