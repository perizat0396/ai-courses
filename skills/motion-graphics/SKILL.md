# Motion-графика

Рендер — скрипт `scripts/motion.py` из папки этого скилла (Pillow + ffmpeg, 30 кадров/с).

## Порядок работы
1. Уточни (если не сказано): текст, формат (9:16 Reels/сторис, 1:1, 4:5, 16:9), фирменные цвета (HEX), есть ли логотип и шрифт из бренд-бука. По умолчанию: фон `#111111`, текст `#FFFFFF`, акцент `#FFC21A`.
2. Сначала сделай **превью-кадр** (`--preview --out preview.png`) и покажи пользователю. Правь цвета и текст на превью — это быстро.
3. После согласования рендери видео. Сохрани в `/mnt/user-data/outputs/` и дай ссылку.

## Шаблоны
| Шаблон | Для чего | Пример |
|---|---|---|
| `title` | Заголовок + подзаголовок | `--template title --text "День открытых дверей" --subtext "23 ноября · 10:00"` |
| `counter` | Растущая цифра | `--template counter --value 1200 --text "абитуриентов в прошлом году"` (`--prefix`, `--suffix "%"`) |
| `quote` | Цитата по словам + автор | `--template quote --text "..." --subtext "Ректор ВКУ" --duration 8` |
| `lowerthird` | Плашка «Имя / должность» поверх видео | `--template lowerthird --text "Имя Фамилия" --subtext "должность" --alpha --format 16:9` |
| `outro` | Логотип + призыв + дата | `--template outro --logo logo.png --text "Ждём вас" --subtext "23 қараша · 10:00"` |
| `list` | Пункты по очереди | `--template list --text "5 причин прийти" --items "Пункт 1|Пункт 2|Пункт 3"` |

Общие параметры: `--format 9:16`, `--duration 5`, `--bg/--fg/--accent "#HEX"`, `--font бренд-Bold.ttf`, `--font-regular бренд-Regular.ttf`, `--out файл.mp4`.

## Прозрачный фон
`--alpha` → файл `.mov` (ProRes 4444) с прозрачностью. В CapCut: **Наложение (Overlay)** → добавить файл поверх видео. Используй для `lowerthird` и для титров поверх съёмки.

## Правила
- Текст на экране — коротко: заголовок до 7 слов, подпись до 12.
- Цифры и имена — только от пользователя, проверенные.
- Казахский и русский рендерятся корректно; для фирменного шрифта проверь, что в нём есть казахские буквы (иначе предупреди).
- Если нужно что-то сложнее шаблонов — напиши свою функцию кадра в Python по образцу из `motion.py` (Pillow, кадры в ffmpeg через stdin).
