# Пакет фото

Скрипт `scripts/photo_pack.py` из папки этого скилла.

## Порядок работы
1. Посмотри на фото: где главный объект (лица, сцена, спикер). Задай точку интереса `--focus x,y` (0..1): для людей обычно `0.5,0.35`, для объекта по центру — `0.5,0.5`.
2. Режим:
   - `--mode crop` — заполнить кадр, края обрезаются (по умолчанию);
   - `--mode fit` — фото целиком на размытом фоне (если важно ничего не обрезать: групповое фото, документ, афиша).
3. Логотип — только официальный файл от пользователя: `--logo logo.png --logo-pos br`.
4. Запусти, проверь результат глазами (открой 9:16 — не обрезаны ли головы). Если обрезаны — поменяй `--focus` или режим.
5. Сохрани в `/mnt/user-data/outputs/` с `--zip` и дай ссылку на архив.

```
python scripts/photo_pack.py фото1.jpg фото2.jpg --out pack --formats 1:1,4:5,9:16,16:9 --focus 0.5,0.35 --logo logo.png --zip
```

| Формат | Где используется |
|---|---|
| 1:1 (1080×1080) | Лента Instagram, Facebook |
| 4:5 (1080×1350) | Лента Instagram — занимает больше экрана |
| 9:16 (1080×1920) | Сторис, Reels-обложка |
| 16:9 (1920×1080) | Сайт, баннер, YouTube |

## Правила
- Публикуй только фото людей, давших согласие. Не меняй лица и не «улучшай» внешность.
- Цветокоррекцию и ретушь делай через Adobe (коннектор) — этот скилл для форматов и логотипа.
