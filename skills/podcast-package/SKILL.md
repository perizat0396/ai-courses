# Пакет выпуска подкаста

## До записи
- 10 вопросов: 2 разминочных → 5 по сути → 2 «человеческих» → 1 финальный совет. Без вопросов «да/нет».
- Сценарий: вступление ведущего, представление гостя, блоки с хронометражем, финал.

## После записи (на вход — расшифровка)
1. Конспект — 5 главных мыслей, по одному предложению.
2. 3 цитаты гостя **дословно**, до 25 слов, с таймкодом. Не перефразируй.
3. Таймкоды разделов: `00:00 — Тема`.
4. Описание выпуска — до 400 знаков.
5. 3 поста-анонса, в каждом одна цитата.

## Правила
- Имена, должности и термины из расшифровки отметь для проверки.
- Если расшифровка без таймкодов — не придумывай их, попроси версию с таймкодами.
- Язык ответа — язык выпуска; по запросу дай вторую версию (KZ/RU).
