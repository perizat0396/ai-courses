# Видеоинструменты (ffmpeg)

Все операции — через скрипт `scripts/vt.py` из папки этого скилла. Он сам найдёт ffmpeg (или установит `imageio-ffmpeg`) и шрифт с казахскими буквами.

## Порядок работы
1. Скопируй загруженное видео в рабочую папку. Сначала выполни `python scripts/vt.py info ВИДЕО` — узнай длительность, размер, есть ли звук.
2. Выбери команду по задаче (таблица ниже). Если задача из нескольких шагов — делай по очереди, промежуточные файлы называй понятно.
3. Сохрани итог в `/mnt/user-data/outputs/` (если папки нет — в текущую) и дай пользователю ссылку на файл.
4. Кратко скажи, что сделано: размер, длительность, вес файла.

| Задача пользователя | Команда |
|---|---|
| Сделать вертикальным для Reels / сторис | `vertical IN OUT --mode blur` (размытый фон, ничего не обрезает) или `--mode crop` (заполнить кадр) |
| Квадрат / 4:5 / горизонталь | `vertical IN OUT --size 1:1` (4:5, 16:9) |
| Вырезать фрагмент | `trim IN OUT --start 00:00:12 --end 00:00:40` |
| Уменьшить вес | `compress IN OUT --for telegram` (instagram, web) |
| Склеить несколько клипов | `concat OUT IN1 IN2 IN3 --size 9:16` |
| Поставить логотип | `logo IN LOGO.png OUT --pos tr --width 0.18` |
| Вшить субтитры | `subs IN SUBS.srt OUT [--font бренд.ttf] [--size 54]` |
| Звук для расшифровки | `audio IN OUT.mp3` |
| GIF-превью | `gif IN OUT.gif --start 3 --dur 4 --width 540` |
| Обложка | `thumb IN OUT.jpg --time 00:00:02` |
| Выровнять громкость | `loud IN OUT` |

## Субтитры
Если .srt нет — сначала напиши его (скилл `reels-script` или по тексту пользователя), строки до 35 знаков. Скрипт рисует субтитры сам — казахские ә, ғ, қ, ң, ө, ұ, ү, һ, і отображаются правильно.

## Ограничения — предупреди пользователя
- В Claude можно загрузить файл примерно до 30 МБ. Длинное видео пусть сначала сожмёт на телефоне или в CapCut, либо пришлёт фрагмент.
- Сложный монтаж (переходы, музыка по битам, цветокоррекция) — в CapCut; этот скилл для быстрых технических операций.
- Не обрабатывай чужие ролики с чужой музыкой для публикации.
