## Практика қалай өтеді
Әр тапсырма екі қадамнан тұрады: **А. Үлгі** — дайын материал мен промпт бойынша бәріміз бірге орындаймыз; **Б. Өз тапсырмаңыз** — дәл солай, бірақ өз материалыңызбен. Промпттарды жақтаудағы «Көшіру» батырмасымен көшіріңіз — қолмен терудің қажеті жоқ.

## Практикаға арналған материалдар
- **1-тапсырмаға арналған сурет:** [суретті ашу](/lessons/m2/stol_cvety.png) — суретті басып, саусағыңызды ұстап тұрыңыз, содан кейін «Суретті сақтау» (компьютерде — тышқанның оң жақ батырмасы → «Суретті басқаша сақтау»).
- **3-тапсырмаға арналған құжат:** [«Оқу орталығының апталық іс-шаралар жоспарын» жүктеу](/lessons/m2/Is-sharalar_zhospary_KZ.docx)

## 1-тапсырма. Дайын суретті өзгертеміз — 12 минут
**А. Үлгі**
1. ChatGPT-те «+» батырмасын басыңыз.
2. «Фото» бөлімін таңдап, сақталған үстел суретін табыңыз.
3. Промптты көшіріп, жіберіңіз:
```
Осы суретті өзгерт: гүлдердің түсін қызылдан сарыға ауыстыр, үстелге кішкентай сыйлық қорапшасын қос және фонды мерекелік қыл. Суреттің негізгі композициясын сақта.
```
Содан кейін сол чатқа:
```
Суретті ашығырақ қыл, жылы түстерді қолдан және сапасын жақсарт.
```
> **Ойланыңыз:** барлығында бірдей шықты ма? Жоқ — ЖИ әр жолы сәл басқаша салады. Қажетті өзгеріс орындалмаса, өтінішті нақтылаңыз.

**Б. Өз тапсырмаңыз.** Қасыңыздағы бір нәрсені (үстел, терезе, гүл) суретке түсіріп, үлгі бойынша өзгертіңіз — тік жақшадағы сөздерді ауыстырыңыз:
```
Осы суретті өзгерт: [нені ауыстыру], [нені қосу], [фон қандай болсын]. Негізгі композицияны сақта.
```
Кеңестер: «терезенің сыртын қысқы көрініс қыл», «терезе алдына мысық қос», «қабырғаларды ашық жасыл түске боя».

## 2-тапсырма. Құттықтау ашықхаты — 15 минут
**А. Үлгі.** «Жаңа чат» батырмасын басып, жіберіңіз:
```
Туған күнге арналған әдемі құттықтау ашықхатын жаса. Гүлдер, сыйлық қорапшасы және жеңіл алтын түсті өрнектер қос. Ортасына үлкен әрі анық әріптермен «Туған күніңмен!» деп жаз. Дизайн жылы, сәнді және ересек адамға арналған болсын. Ашықхатты тік пішімде жаса.
```
Сол чатқа қолтаңба қосыңыз:
```
Ашықхаттың төменгі бөлігіне «Құрметпен, әріптестеріңіз» деген жазу қос. Қалған дизайнды өзгертпе.
```
> **Жазуды тексеріңіз!** ЖИ суреттегі әріптерде, әсіресе қазақ әріптерінде (ә, ғ, қ, ң, ө, ұ, ү, һ, і) жиі қателеседі. Қате болса:
```
Ашықхаттың дизайнын өзгертпе. Жазуды түзетіп, дәл осылай жаз: «Туған күніңмен!»
```

**Б. Өз ашықхатыңыз.** Өз себебіңізді таңдаңыз: мерейтой, Наурыз, қоныс той, Мұғалімдер күні. Жақшадағы сөздерді ауыстырыңыз:
```
[Мерейтойға] арналған әдемі құттықтау ашықхатын жаса. [Не салу керек] қос. Ортасына үлкен әріптермен «[сіздің мәтініңіз]» деп жаз. Дизайн жылы әрі сәнді, ересек адамға арналған, тік пішімде.
```
**Қалай сақтау керек:** ашықхатты басыңыз → жүктеу белгішесі. Кейін оны WhatsApp-қа жіберуге болады.

## 3-тапсырма. Құжатпен жұмыс — 18 минут
**А. Үлгі.** «Оқу орталығының апталық іс-шаралар жоспары» құжатын жүктеп алыңыз (сілтеме беттің жоғарғы жағында).
1. «Жаңа чат», содан кейін «+» батырмасын басыңыз.
2. «Файлдар» бөлімін таңдап, құжатты «Жүктеулер» қалтасынан табыңыз.
3. Промпттарды кезекпен жіберіңіз, әрқайсысын алдыңғысына жауап келген соң:
```
Тіркелген құжатты оқы. Оның негізгі мазмұнын бес тармақпен қарапайым сөзбен жаз. Маңызды күндерді, уақытты және өтетін орнын бөлек көрсет.
```
```
Осы құжат негізінде WhatsApp тобына жіберуге арналған қысқа әрі түсінікті хабарлама дайында.
```
```
Құжаттағы ақпаратты екі бағаннан тұратын кесте түрінде көрсет: «Маңызды ақпарат» және «Не істеу керек».
```
> **Құжатпен салыстырыңыз:** ChatGPT негізгі ойды дұрыс түсінді ме? Күнді немесе орынды өткізіп алмады ма? Топқа жібермес бұрын нені тексеру керек?

Жауапқа күмәндансаңыз:
```
Тек тіркелген құжат негізінде жауап бер. Құжатта ақпарат болмаса, «Құжатта бұл жоқ» деп жаз.
```

**Б. Өз тапсырмаңыз.** Жеке деректері жоқ кез келген мәтінді суретке түсіріңіз: стендтегі хабарландыру, тұрмыстық құралдың нұсқаулығы, рецепт. Фотоны «+» арқылы тіркеп, жазыңыз:
```
Суреттегі мәтінді оқып, мұнда не жазылғанын және маған не істеу керек екенін үш тармақпен қарапайым сөзбен түсіндір.
```

> **Қауіпсіздік.** Төлқұжат және банк деректері, құпиясөздер, медициналық ақпарат немесе басқа адамдардың жеке мәліметтері бар құжаттарды жүктемеңіз.
