## Claude скиллдері: бір рет түсіндірдіңіз — әрі қарай Claude өзі жасайды

Скилл (skill) — SKILL.md нұсқаулығы және қажет болса файлдар салынған папка: мысалдар, үлгілер, скрипттер, біздің логотип. Промт бір чатта ғана өмір сүреді, ал скилл — барлық чатта: Claude оны қашан қосу керектігін өзі түсінеді. Скиллдер тегін тарифте де жұмыс істейді, бірақ файл жасау мүмкіндігін қосу керек.

**Айырмашылығы бір жолда:** промт — бір реттік тапсырма; жоба — бір тақырыпқа арналған файлдар папкасы; скилл — барлық жерде жұмыс істейтін лауазымдық нұсқаулық.

### Қалай қосу керек

1. **Баптаулар → Мүмкіндіктер** → «Файлдарды жасау және өңдеу» қосу.
2. **Customize → Skills → «+» → Create skill → Upload a skill.**
3. Скиллдің ZIP файлын жүктеу (ашпай-ақ).
4. Скилл қосқышы қосулы екенін тексеру.

Немесе оңайырақ: Claude-қа «Университетіміздің стилінде пост жазатын скилл жасап бер. Міне 5 мысал» деп жазыңыз — ол өзі құрастырып, сақтауды ұсынады.

> Мәзір атаулары жаңартулар кезінде кейде өзгереді. Таппасаңыз — оң жақ төменгі бұрыштағы ЖИ-көмекшіден сұраңыз.

## ChatGPT + Claude байланысы: ChatGPT дайындайды және салады, Claude жазады және жинайды

Екі ЖИ де барлығын дерлік істей алады, бірақ әрқайсысының өз күшті жағы бар. Команда болып жұмыс істейміз: біреуі жоба жасайды, екіншісі пысықтап, тексереді.

| Міндет | ChatGPT | Claude |
|---|---|---|
| Идеялар, ми шабуылы, трендтер | Күштірек | Жақсы |
| Сурет генерациясы | Өзі салады | Фото салмайды, бірақ промт жазады, инфографика мен карусель жасайды |
| Ұзын мәтіндер, стиль, редакция | Жақсы | Күштірек: жандырақ, шаблоны аз |
| Файлдар, бейне, кодпен монтаж | Жақсы | Күштірек + скиллдер |
| Жүріп келе жатып дауыспен | Ыңғайлырақ | Бар |

### Басты тәсіл — «бір ЖИ-ден екіншісіне промт»

1. ChatGPT-те: «Claude үшін Рөл-Міндет-Контекст-Референс-Формат-Шектеулер формуласы бойынша толық промт құрастыр. Міндет: […]. Алдымен маған сұрақ қой».
2. Дайын промтты көшіреміз → Claude-қа қоямыз → мәтін аламыз.
3. Мәтінді ChatGPT-ке қайтарамыз: «Сен бас редакторсың. 3 әлсіз тұсын тауып, түзету ұсын». Түзетулер — қайтадан Claude-қа.

### Дайын сценарийлер

| Сценарий | Қадамдар |
|---|---|
| Пост + сурет | Claude пост пен суретке промт жазады → ChatGPT салады → логотипті Canva-да қоямыз |
| Іс-шарадан жаңалық | Диктофон/жазбалар → Claude: сайтқа жаңалық + RU/KZ посттар → ChatGPT: қазақша мәтінді тексеру |
| Reels | ChatGPT: трендтер бойынша 10 идея → Claude: кадрлары бар сценарий → түсірілім → монтаж (2-деңгей) |
| Контент-жоспар | ChatGPT: айдың ақпараттық себептері → Claude: айдарлары мен күндері бар кесте-күнтізбе |

> Фактілерді, күндерді, есімдер мен лауазымдарды әрқашан адам тексереді. Студенттер мен қызметкерлердің дербес деректерін жеке аккаунттарға жүктемеңіз.
