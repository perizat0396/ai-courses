Алты карточка: әрқайсысында дайын референс пен промт. Тек [жақшаларды] өз деректеріңізге ауыстырыңыз — 5–10 минутта дайын контент аласыз. **Әр дайын пост пен суретте — біздің логотип** ([жүктеп алу](/brand/vku-logo-blue.png)).

## 1-карточка. Іс-шара анонсы (Instagram, Claude)

Референс — пост осылай естілуі керек:

```
4 жылдан кейін кім болатыныңды түсінуге 3 сағатың бар 🎓
Сенбі, 10:00 — Ашық есік күні.
Зертханалар, тірі сабақтар, сценарийсіз студенттер және грант туралы барлық сұрақтарға жауап.
Тіркелу — профиль басындағы сілтеме арқылы.
```

Промт:

```
Сен — университеттің SMM-редакторысың. Instagram-ға анонс жаз.
Оқиға: [атауы], [күні, уақыты, орны], не болады: [3–4 тармақ].
Аудитория: [кім]. Мақсат: [тіркелу / келу].
Стиль бойынша референс: [жоғарыдағы референсті қою].
Формат: бірінші жолда хук-сұрақ немесе интрига, 80 сөзге дейін, үндеу, 5 хэштег. 3 нұсқа.
Кеңсе тілінсіз. Қазақ және орыс тілдерінде нұсқаларын жаса.
```

## 2-карточка. Оқиға қорытындысы бойынша жаңалық (сайт, Claude)

Референс — «төңкерілген пирамида» құрылымы: басты ақпарат бірінші абзацта (не, қайда, қашан, қанша қатысушы) → спикердің дәйексөзі → толығырақ → әрі қарай не болады.

```
Сен — баспасөз қызметінің журналисісің. Міне, іс-шарадан жазбаларым: [жазбаларды немесе дауыстық хабардың транскрипциясын қою].
Сайтқа «төңкерілген пирамида» құрылымымен 200–250 сөздік жаңалық жаз.
10 сөзге дейінгі 3 тақырып нұсқасын және бір сөйлемдік лид бер.
Жазбаларда жоқ фактілерді қоспа; бірдеңе жетпесе — сұра.
```

## 3-карточка. Бір жаңалық — үш алаң (Claude)

Референс: Telegram — қысқа әрі нақты, сілтемемен; Instagram — эмоция және адамдар; Facebook — ресмирек, ата-аналар мен серіктестерге арналған.

```
Осы жаңалықтан [қою] үш пост жаса:
Telegram — 50 сөзге дейін, факт + сілтеме;
Instagram — 80 сөзге дейін, хук, эмоция, үндеу, хэштегтер;
Facebook — 120 сөзге дейін, байсалды үн.
Бәрі қазақ және орыс тілдерінде. Кестемен рәсімде: алаң | RU | KZ.
```

## 4-карточка. Бөтен сәтті постты талдау (кері промтинг, ChatGPT немесе Claude)

Референс: басқа ЖОО-ның қамтуы жоғары постының скриншоты.

```
[скриншотты тіркеу]
Бұл пост неге жұмыс істейді? Тәсілдерге бөліп бер: хук, құрылым, үн, көлем, визуал, үндеу.
Содан кейін дәл осы тәсілдермен [біздің тақырып] туралы пост жаз. Мәтінді көшірме — тек тәсілдерді ал.
```

## 5-карточка. Постқа сурет (Claude → ChatGPT)

Стиль референсі: ашық репортаждық фотосурет, табиғи жарық, іс үстіндегі студенттер, детальдарда фирмалық көк #004AAD; жоғарыда тақырыпқа орын.

Claude-қа промт:

```
Осы постқа [қою] ChatGPT-те сурет генерациялауға арналған промт жаз.
Стиль: репортаждық фото, табиғи жарық, детальдарда көк #004AAD,
4:5 форматы, жоғарыда мәтінге бос орын, суретте жазулар мен логотиптер болмасын.
Промттың 2 нұсқасын бер.
```

Содан кейін промт → ChatGPT-ке → сурет. Тақырыпты және **міндетті түрде біздің логотипті (түпнұсқа файл)** Canva немесе CapCut-та қосамыз: ЖИ әріптерді, әсіресе қазақ әріптерін жиі бұрмалайды.

## 6-карточка. 30 секундтық Reels сценарийі (ChatGPT → Claude)

Құрылым референсі: 0–3 с хук → 3–20 с фактілері бар үш жылдам кадр → 20–27 с эмоция немесе дәйексөз → 27–30 с үндеу және логотип.

ChatGPT-ке промт:

```
Университет үшін [тақырып] бойынша қазір трендте тұрған форматтарда 10 Reels идеясын бер.
Әрқайсысына: бір сөйлемдік хук және нені түсіру керек.
```

Claude-қа промт (ең жақсы идеямен):

```
Мына идея бойынша 30 секундтық Reels сценарийін жаз: [идея].
Құрылым: хук 0–3 с, фактілер 3–20 с, эмоция 20–27 с, үндеу және логотип 27–30 с.
Кесте: уақыт | кадр (не түсіреміз) | экрандағы мәтін | кадр сыртындағы мәтін.
Телефонға 15 минутта, арнайы техникасыз түсіреміз.
```

Бұл сценарий — 2-деңгейге дайындама: түсірілген роликті скиллдермен монтаждаймыз.

## Өз практикаңыз: үлгі, скилл және алғашқы пост

- [ ] Промт үлгісін ЖОО-ның жақын арадағы нақты ақпараттық себебіне толтыру.
- [ ] 2 референс табу (өз ең жақсы постыңыз + бөтен пост) және оларды Claude-та кері промтингпен талдау.
- [ ] Байланысты іске қосу: ChatGPT → промт → Claude → мәтін → ChatGPT → сурет → логотип. Нәтиже: суреті мен логотипі бар RU және KZ тілдеріндегі дайын пост.
- [ ] Claude-тан 5 постыңыз бойынша «ШҚУ брендінің дауысы» скиллін жинауды сұрап, оны сақтау.

Скиллге арналған промт:

```
Маған «ШҚУ брендінің дауысы» скиллін жасап бер. Міне, ең жақсы 5 постымыз [қою].
Онда сипатта: үні, көлемі, құрылымы, сүйікті және тыйым салынған сөздер, хэштегтер, қазақша нұсқаның ережелері.
Фирмалық түс #004AAD, әр визуалда Amanzholov University логотипі (файл тіркелген).
«Осылай жазамыз / осылай жазбаймыз» мысалдарын қос. Скилл ретінде сақта.
```
