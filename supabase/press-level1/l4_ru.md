## Карточка 1. Анонс мероприятия (Instagram, Claude)

Референс — так должен звучать пост:

```
У тебя 3 часа, чтобы понять, кем ты будешь через 4 года 🎓
Суббота, 10:00 — День открытых дверей.
Лаборатории, живые пары, студенты без сценария и ответы на все вопросы про грант.
Регистрация — ссылка в шапке профиля.
```

Промт:

```
Ты — SMM-редактор университета. Напиши анонс для Instagram.
Событие: [название], [дата, время, место], что будет: [3–4 пункта].
Аудитория: [кто]. Цель: [регистрации / приход].
Референс по стилю: [вставить референс выше].
Формат: хук-вопрос или интрига в первой строке, до 80 слов, призыв, 5 хэштегов. 3 варианта.
Без канцелярита. Сделай версии на русском и казахском.
```

## Карточка 2. Новость по итогам события (сайт, Claude)

Референс — структура «перевёрнутая пирамида»: главное в первом абзаце (что, где, когда, сколько участников) → цитата спикера → детали → что дальше.

```
Ты — журналист пресс-службы. Вот мои заметки с мероприятия: [вставить заметки или расшифровку голосового].
Напиши новость на сайт по структуре «перевёрнутая пирамида», 200–250 слов.
Дай 3 варианта заголовка до 10 слов и лид в одно предложение.
Не добавляй фактов, которых нет в заметках; если чего-то не хватает — спроси.
```

## Карточка 3. Одна новость — три площадки (Claude)

Референс: Telegram — коротко и по делу, с ссылкой; Instagram — эмоция и люди; Facebook — официальнее, для родителей и партнёров.

```
Из этой новости [вставить] сделай три поста:
Telegram — до 50 слов, факт + ссылка;
Instagram — до 80 слов, хук, эмоция, призыв, хэштеги;
Facebook — до 120 слов, сдержанный тон.
Всё на русском и казахском. Оформи таблицей: площадка | RU | KZ.
```

## Карточка 4. Разбор чужого удачного поста (обратный промтинг, ChatGPT или Claude)

Референс: скриншот поста другого вуза с большим охватом.

```
[прикрепить скриншот]
Почему этот пост работает? Разложи на приёмы: хук, структура, тон, длина, визуал, призыв.
Потом напиши по этим же приёмам пост про [наша тема]. Текст не копируй — только приёмы.
```

## Карточка 5. Картинка к посту (Claude → ChatGPT)

Референс стиля: светлая репортажная фотография, естественный свет, студенты в действии, фирменный синий #004AAD в деталях; место под заголовок сверху.

Промт для Claude:

```
К этому посту [вставить] напиши промт для генерации изображения в ChatGPT.
Стиль: репортажное фото, естественный свет, синий #004AAD в деталях,
формат 4:5, свободное место сверху под текст, без надписей и логотипов на картинке.
Дай 2 варианта промта.
```

Затем промт → в ChatGPT → картинка. Заголовок и **обязательно наш логотип (оригинальный файл)** добавляем в Canva или CapCut: ИИ часто искажает буквы, особенно казахские.

## Карточка 6. Сценарий Reels 30 секунд (ChatGPT → Claude)

Референс структуры: 0–3 с хук → 3–20 с три быстрых кадра с фактами → 20–27 с эмоция или цитата → 27–30 с призыв и логотип.

Промт для ChatGPT:

```
Дай 10 идей Reels для университета на тему [тема] в форматах, которые сейчас в тренде.
Для каждой: хук в одну фразу и что снимать.
```

Промт для Claude (с лучшей идеей):

```
Напиши сценарий Reels на 30 секунд по идее: [идея].
Структура: хук 0–3 с, факты 3–20 с, эмоция 20–27 с, призыв и логотип 27–30 с.
Таблица: время | кадр (что снимаем) | текст на экране | текст за кадром.
Снимаем на телефон за 15 минут, без спецтехники.
```

Этот сценарий — заготовка для уровня 2: снятый ролик смонтируем со скиллами.

## Своя практика: шаблон, скилл и первый пост

- [ ] Заполнить шаблон промта под ближайший реальный инфоповод вуза.
- [ ] Найти 2 референса (свой лучший пост + чужой) и разобрать их в Claude обратным промтингом.
- [ ] Прогнать связку: ChatGPT → промт → Claude → текст → ChatGPT → картинка → логотип. Результат: готовый пост на RU и KZ с изображением и логотипом.
- [ ] Попросить Claude собрать скилл «Голос бренда ВКУ» из ваших 5 постов и сохранить его.

Промт для скилла:

```
Сделай мне скилл «Голос бренда ВКУ». Вот 5 наших лучших постов [вставить].
Опиши в нём: тон, длину, структуру, любимые и запретные слова, хэштеги, правила для казахской версии.
Фирменный цвет #004AAD, на каждом визуале логотип Amanzholov University (файл прикреплён).
Добавь примеры «так пишем / так не пишем». Сохрани как скилл.
```
